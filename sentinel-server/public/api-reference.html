POST /api/auth/register
Creates a new Sentinel Guardian account. Links the mobile Device ID (ANDROID_ID) to the user's email and bcrypt-hashed password.
No Auth Required BCrypt Password Hash Device Binding
POST /api/auth/login
Authenticates a user with email + password. Returns a signed JWT token (expires in 7 days) and the HMAC secret for request signing.
No Auth Required Returns JWT Returns HMAC Secret
GET /api/user/profile
Fetches the logged-in user's profile, including their name, device ID, and trust settings.
JWT Required HMAC Signed
POST /api/emergency/trigger
Reports an Emergency Lockdown event to the server (e.g., Frida detected, price mismatch). Logged to the blockchain audit ledger.
JWT Required Blockchain Anchored Risk Score Logged

Marks an active emergency as resolved after a successful biometric verification. Updates the immutable blockchain record.
JWT Required Biometric Verified
POST /api/tasks

Sentinel Multi-Layer Security Firewall
🔴
LAYER 1: HARDWARE ROOT OF TRUST
Keys generated inside Android's StrongBox / Trusted Execution Environment (TEE). Keys never leave the secure chip — not even Sentinel code can read the raw key. Uses AES-256-GCM encryption.
CHIP-LEVEL
🟠
LAYER 2: APPLICATION INTEGRITY
At startup, the APK's SHA-256 signature is verified. If the app is repackaged or tampered with, the check fails and the system enters emergency lockdown. Also checks for Rooting (10 methods), Magisk, and emulators.
OS-LEVEL
🔵
LAYER 3: NETWORK FIREWALL
All API requests are signed with an HMAC-SHA256 signature (to prevent replay attacks). The server verifies each request's signature and timestamp before processing. Stale or unsigned requests are rejected (401).
TRANSPORT-LEVEL
🟢
LAYER 4: BEHAVIORAL AI ENGINE
The on-device Risk Calculator runs 24/7, scoring every app action. It uses burst detection, statistical value anomaly, and context multipliers (night-time 1.5×). No cloud needed — fully local AI.
APPLICATION-LEVEL
🟣
LAYER 5: NATIVE C++ KERNEL BYPASS
A C++ NDK native library uses Linux Syscall (SVC) instructions to bypass the standard Java layer. This detects Frida and memory hooking tools even when they have hidden themselves from Java-level APIs.
KERNEL-LEVEL
⛓️
LAYER 6: BLOCKCHAIN AUDIT LEDGER
Every security event is Hash-Chained (each log references the previous log's hash) and then anchored to a smart contract on the blockchain. This creates an immutable, unalterable audit trail that even an admin cannot delete.
IMMUTABLE-LEDGER
How to Upgrade The Firewall System
🚀 Upgrade: Certificate Pinning
Currently, the app trusts any server certificate. Upgrade: Add certificate pinning in RetrofitClient.kt using OkHttp's CertificatePinner. This prevents man-in-the-middle attacks on the API.
🔐 Upgrade: Prompt Firewall
Expand the onPromptReceived() in RiskCalculator.kt from 5 keywords to a full NLP blocklist of 50+ suspicious command patterns, including social engineering and privilege escalation phrases.
⚡ Upgrade: WebSocket Push
Replace the 1-second polling of /api/commands/pending with a persistent WebSocket connection. This reduces latency from ~1s to near-zero, making the Remote Lock virtually instant.
